## 🚀 Featured Projects

### 🏆 [Atahad](https://github.com/FaiAlharthi/Atahad) – Group Challenge App
- REST API with Spring Boot and Spring Security to control who can use each endpoint.
- Weekly group rules: how members pay, the minimum payment, and removing a member after repeated failures.
- n8n automations connected to the API with a secret key.
- Built with Java, Spring Boot, MySQL, and Flutter.

### 💼 [Tumooh](https://github.com/FaiAlharthi/Tumooh-Capstone3) – AI Job Application Tracker
- Tracks every job application, with 1,008 Saudi companies you can search by English name, Arabic name, or nickname.
- Reads your Gmail every night, uses Gemini to find job emails, updates the status, and sends WhatsApp alerts.
- Built with Java, Spring Boot, MySQL, and the Gemini API.

### 🧭 [Masar](https://github.com/FaiAlharthi/masar) – AI Guide for Business Licenses in Saudi Arabia
- A chat that builds a license roadmap for your business: steps, requirements, cost, and time.
- Uses Claude tools so answers come only from official data, not from the model's memory.
- 🥇 **Gold evaluation** at the Kanz AI Training Hackathon, with the Ministry of Human Resources and Social Development.
- Built with Next.js, TypeScript, Tailwind CSS, and the Claude API.

### 📑 [Procify](https://github.com/FaiAlharthi/Procify) – AI Procurement Platform
- Covers the full RFP process: create an RFP, invite vendors, upload PDF proposals, and compare them.
- AI gives each proposal a score from 0 to 100, Gemini suggests vendors, and a chat helps write the RFP.
- Built with React, FastAPI, SQLAlchemy, and JWT authentication.
